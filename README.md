# Atari_Breakout_DQN
This project implements a Deep Q-Network (DQN) with a Convolutional Neural Network (CNN) to play Atari Breakout using only pixel inputs and game rewards. Powered by Stable-Baselines3 and PyTorch, our RL agent transitions from random actions to structured paddle controls. We compare baseline and trained performance with side-by-side gameplay GIFs.
